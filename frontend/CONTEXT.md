# mm/frontend/ — React + Vite Web App

TypeScript + Tailwind CSS frontend for movie management.

## Structure

- `src/pages/` — AccountPage, AdminPage, ListsPage, MoviesPage, PeoplePage, PersonDetailPage
- `src/components/` — AddMovie, AuthScreen, MovieCard, MovieDetail, MovieDetailPanel, MoviePosterCard, PeopleManager, RatingPrompt, UserStats, features/, layout/, ui/
- `src/contexts/` — AuthContext, MoviesContext, RankingContext
- `src/hooks/` — usePeople, useRankingSession, useSync
- `src/services/` — api.ts, omdbAPI.ts, tmdbAPI.ts
- `src/utils/` — constants, helpers, movies, people
